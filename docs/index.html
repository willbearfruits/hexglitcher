HexGlitcher

Databending, made accessible.

A layered, realtime, non-destructive glitch-art studio for images & video. Corrupt raw bytes, sort pixels, glitch video frame-by-frame — and watch it happen live.

⬇ Flatpak (Linux) Install from source ★ GitHub

What it does

🧱

Non-destructive layers

Stack glitch layers over the original with blend modes & opacity. Nothing is ever baked in until you export.

🎚️

Realtime preview

Drag a slider, see it instantly. Rendering runs off the UI thread, so it never freezes.

🎬

Video

Open a clip, scrub or play it, glitch every frame through the same op-stack, and export an MP4.

🎨

Looks & 🎲 Surprise

One-click curated presets, and a dice button for instant happy accidents.

💾

Re-editable projects

Save your whole stack as a .glitch recipe; reopen and keep tweaking. Export images & GIFs.

🧩

Two op domains

Byte ops corrupt the raw file before decode; pixel ops transform the image after — split at one decode boundary.

The studio

22 operations

Corruption · random / sort / shift / chunk-shuffle / hex find-replace Audio databend · echo · tremolo · flanger · bitcrush · overdrive Inject / Mix · weave another file's bytes in Format · PNG filter-rewrite · JPEG quantize / recompress Decoder hacks · wrong-width shear · planar tearing Pixel · threshold sort · channel shift · displacement · noise

Get it

🐧 Linux — Flatpak

One-click, no Python setup.

# download HexGlitcher.flatpak from the release, then
flatpak install --user HexGlitcher.flatpak
flatpak run io.github.willbearfruits.HexGlitcher

🛠️ From source — any OS

Python 3.10+ · ffmpeg for video export.

git clone https://github.com/willbearfruits/hexglitcher
cd hexglitcher && pip install -e .
hexglitcher # or: hexglitcher image.png
